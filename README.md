# AI Advent Challenge — День 4

Веб-лаборатория температуры: один и тот же набор запросов при `temperature = 0`, `0.7` и `1.2`.

## Что умеет

- **Эксперимент**: 2 типа задач × 3 температуры × N прогонов (3–10, по умолчанию 5).
  - логическая задача с одним правильным ответом (25 лошадей → 7 забегов, ответ — число);
  - генерация рецепта бутерброда в JSON-объекте `{"recipe":"..."}`.
- **Песочница**: свой промпт, температура 0–2, 1–5 прогонов.
- **Метрики**:
  - логика: верных/N, формат соблюдён/N, уникальных ответов/N, средняя похожесть;
  - генерация: формат JSON-объекта `{"recipe":"..."}`, уникальных рецептов/N, средняя похожесть;
  - средние токены и время;
  - отдельный вывод по `temperature = 0`: совпали ли все ответы.
- **Выводы**: где температура 0 стабильна, где высокая ломает формат/правильность, где разнообразие полезно, а где вредит, и рекомендация по температуре.

## Важно про DeepSeek

В thinking-режиме `temperature` **не работает**. Поэтому приложение всегда отправляет:

```json
{"thinking": {"type": "disabled"}}
```

и только после этого `temperature` реально влияет на ответ. `temperature = 0` — максимально детерминированный режим, но не железная гарантия одинаковых ответов; это проверяется по прогонам.

## Запуск

1. Вставьте ключ DeepSeek в `api_key.txt` (только ключ):

   ```
   sk-...
   ```

2. Запустите:

   ```powershell
   go run .
   ```

3. Откройте http://localhost:8083

## Промпты

Файл `prompts.json` в корне — можно редактировать вручную или в UI (кнопка «Сохранить промпты»):

```json
{
  "logicPrompt": "Есть 25 лошадей и ипподром с 5 дорожками. За один забег можно проверить 5 лошадей; секундомера нет, известен только порядок финиша. Какое минимальное число забегов нужно, чтобы гарантированно определить трёх самых быстрых лошадей в правильном порядке? Ответь строго одним числом, без пояснений.",
  "logicAnswer": 7,
  "generationPrompt": "Придумай рецепт для нового бутерброда. Ответь строго JSON-объектом вида {\"recipe\":\"рецепт\"}. Без пояснений, markdown и текста вокруг."
}
```

## Метрики

- **Формат логики**: ответ — строго одно число. `7` — валидно, `[7]` или `Ответ: 7` — формат сломан, но число извлекается и проверяется отдельно.
- **Формат генерации**: строгий JSON-объект ровно с одним ключом `recipe`, значение — непустая строка. Лишние ключи, текст вокруг или markdown ломают формат.
- **Похожесть**: средняя попарная Jaccard-похожесть по словам (1 — все ответы одинаковые, 0 — все разные).
- **Уникальные рецепты**: нормализованные тексты рецептов, собранные со всех прогонов.

## Настройки (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DEEPSEEK_API_KEY_FILE` | `api_key.txt` | Путь к файлу с ключом |
| `DEEPSEEK_API_KEY` | — | Ключ через окружение (приоритетнее файла) |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | Базовый URL API |
| `DEEPSEEK_MODEL` | `deepseek-v4-flash` | Модель |
| `PORT` | `8083` | Порт сервера |
